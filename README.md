# Java URL Shortener 🔗

*Project 5 of 7 in my "1 Week, 7 Projects" Challenge* 🔥🔥🔥

A lightweight, fast, and responsive URL shortener built from scratch. This project serves as a practical demonstration of backend API design, database integration, and handling HTTP routing efficiently.

## ✨ Features
- **Custom Shortening Algorithm:** Generates unique, URL-safe 6-character alphanumeric short codes (Base62).
- **Fast Redirects:** Utilizes HTTP 302 redirects to seamlessly route users to the original long URL.
- **Modern Web Interface:** Sleek, responsive frontend featuring instant clipboard copying and custom error handling.
- **Robust Database:** Cloud-hosted PostgreSQL on Supabase, featuring an optimized index (`idx_urls_short_code`) for lightning-fast read operations.

## 🛠️ Tech Stack
- **Backend:** Java
- **Web Framework:** Javalin 6 (Lightweight REST API framework)
- **Database:** PostgreSQL (Supabase) via JDBC
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Config Management:** dotenv-java

## 🚀 How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/your-username/java-url-shortener.git
cd java-url-shortener
```

### 2. Set up the Database
Execute the following SQL in your PostgreSQL database to create the required schema and table:
```sql
CREATE SCHEMA IF NOT EXISTS url_shortener;

CREATE TABLE IF NOT EXISTS url_shortener.urls (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    short_code VARCHAR(6) NOT NULL UNIQUE,
    long_url TEXT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_urls_short_code ON url_shortener.urls (short_code);
```

### 3. Configure Environment Variables
Create a `.env` file in the root directory (this file is git-ignored) and add your database credentials:
```env
DB_HOST=your_host_address
DB_PORT=6543
DB_NAME=postgres
DB_USER=your_db_user
DB_PASSWORD=your_db_password
```

### 4. Run the Application
Run the `UrlShortenerApp` main class from your IDE. The server will start on port `8080`.
Visit `http://localhost:8080` in your browser to use the interface!
